# Contributing to RHA Local Voice Engine

We welcome contributions to the RHA Local Voice Engine project.

## Development Phases

Please review the `README.md` and the Engineering Blueprint to understand the project phases.
Do not introduce heavy cloud dependencies or mandatory API keys.

## Pull Requests

- Keep PRs focused on a single module (e.g., STT, LLM streaming).
- Include unit tests.
- Ensure the code works without internet on Android/Termux (if applicable).
